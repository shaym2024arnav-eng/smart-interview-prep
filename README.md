# AI-Powered Smart Interview Preparation System

An intelligent interview preparation platform that generates role-specific interview questions, evaluates answers, provides personalized feedback, and tracks interview performance.

## Features

- User Authentication
- Dashboard
- Interview History
- AI Feedback
- Performance Analytics
- PDF Report Generation
- Responsive UI

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Chart.js

## Installation
```
git clone https://github.com/shaym2024arnav-eng/smart-interview-prep.git
cd smart-interview-prep
pip install -r requirements.txt
python app.py
```
